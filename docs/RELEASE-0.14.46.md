# ChartsHub 0.14.46

- **Langue mémorisée.** Choisissez une langue dans les réglages du Tableau de bord ou dans le Catalogue. ChartsHub enregistre ce choix sur cet appareil et le rétablit à la prochaine ouverture. Le Catalogue et le Tableau de bord suivent le même réglage.
- **Aperçus de traduction.** L’espagnol du Mexique, le chinois simplifié et le japonais sont disponibles dans le sélecteur de langue. Les textes en cours de traduction s’affichent en anglais. Le français et l’anglais restent disponibles.
