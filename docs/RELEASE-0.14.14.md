# ChartsHub Desktop 0.14.14

La vidéo s’affiche dans le lecteur flottant pendant qu’il est ouvert. Le lecteur
principal libère alors sa vidéo ; elle revient à la fermeture du widget et se
synchronise avec la position courante du morceau. La musique continue, et le
réglage « Afficher la vidéo » est conservé.

La piste de la barre de défilement du lecteur flottant devient transparente,
avec une poignée discrète. Le mode de contraste forcé garde la barre native.

Le nettoyage des doublons permet d’enchaîner les mises à la Corbeille sans
actualiser la bibliothèque après chaque copie. Les copies supprimées quittent
la liste immédiatement ; une actualisation peut être lancée à la fin.

Le choix « Conserver toutes les versions » garde les chansons dans la
bibliothèque et retire ce groupe des doublons à traiter. Si une nouvelle
version apparaît, le groupe peut être vérifié à nouveau.

Le catalogue bénéficie du site 1.8.8 : cliquer dans le fond sombre autour d’un
preview le ferme, sans avoir à utiliser le bouton ×. Le lien « OBS source »
est retiré du catalogue et de l’onglet Leaderboard.
