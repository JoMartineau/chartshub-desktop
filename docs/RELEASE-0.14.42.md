# ChartsHub 0.14.42

Dans **Tableau de bord → Catalogue → Quick Import · BÊTA**, vous pouvez examiner une installation reconnue de MelonLoader 0.7.3 sur Linux ou macOS avant de la retirer. Sélectionnez le jeu natif ou le fichier `Clone Hero.exe` utilisé avec Wine, Proton ou CrossOver. Fermez Clone Hero et son lanceur avant de confirmer.

ChartsHub déplace le chargeur reconnu dans un dossier de sauvegarde à côté du jeu. Les mods, les chansons et les réglages restent dans leurs dossiers. Pour rétablir MelonLoader, fermez le jeu et remettez les éléments sauvegardés à leur emplacement d’origine. Les options de lancement personnalisées configurées dans Steam ou dans votre lanceur se gèrent séparément.

Les dispositions x64 officielles ont été vérifiées à partir des archives MelonLoader. La mise en quarantaine et la restauration ont été testées sur des installations synthétiques. Les essais sur de vraies installations de Clone Hero sous Linux et macOS restent à faire.
