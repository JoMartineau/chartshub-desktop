# ChartsHub Desktop 0.14.15

« Supprimer quand même » est disponible pour les doublons dont les notes
diffèrent, y compris entre fichiers .chart et MIDI lisibles. Les différences
de notes, d’audio et des autres fichiers restent affichées avant la décision.
La confirmation Windows mentionne les notes et protège la version conservée.

La section « Supprimer quand même · sélection groupée » regroupe les copies
différentes de plusieurs groupes, après avoir choisi la version à garder pour
chacun. Les cases commencent décochées ; « Tout sélectionner » et « Effacer la
sélection » permettent de préparer le lot. Une seule confirmation Windows
affiche les copies sélectionnées et leurs versions conservées. Les autres
copies restent dans leurs dossiers.

La suppression manuelle envoie uniquement les copies choisies à la Corbeille
Windows. Les fichiers doivent être entièrement vérifiés et
inchangés depuis le scan ; les dossiers partagés ou imbriqués restent protégés.
Le nettoyage peut continuer sans nouveau scan après chaque suppression.
Un lot actualise l’index une seule fois ; « Actualiser à la fin » lance le scan
quand le nettoyage est terminé. Une préparation périmée doit être refaite.
