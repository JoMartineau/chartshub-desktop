# ChartsHub 0.14.41

**Quick Import · BÊTA** propose un assistant pour installer le module dans la bonne copie de Clone Hero. Fermez le jeu et son lanceur, sélectionnez Clone Hero.exe, puis confirmez le dossier Songs. L’assistant télécharge et vérifie l’archive officielle de MelonLoader 0.7.3 et installe Quick Import après votre confirmation. Ouvrez ensuite cette copie du jeu et connectez-la dans ChartsHub. Quick Import reste facultatif et validé avec **Clone Hero 1.1.0.6142-final Stable sur Windows x64**.

Les commandes **Masquer le terminal MelonLoader** et **Afficher le terminal MelonLoader** enregistrent le choix dans la configuration du jeu sélectionné. Fermez Clone Hero et son lanceur avant le changement. Le choix s’applique au prochain lancement du jeu.

Les téléchargements vers le dossier d’export prennent en charge le choix vidéo du catalogue, y compris pour une sélection de charts. Le tableau de bord garde aussi une marge à droite du bouton de thème quand la fenêtre est réduite.

ChartsHub signale chaque nouvelle version une fois et laisse le choix de lancer le téléchargement. Le menu Application permet de vérifier à nouveau les mises à jour.
