# ChartsHub 0.14.45

- **Synchronisation du catalogue ChartsHub.** L’analyse actualise l’index de Songs lorsque ce dossier est aussi la destination des téléchargements. Elle compare les fichiers des charts candidates, ignore les copies identiques et prépare les mises à jour lorsque les fichiers permettent d’identifier la version locale. Si une variante locale diffère, la version du catalogue est installée dans un dossier séparé. Les mises à jour sur place conservent une sauvegarde.
- **Libérer de l’espace.** La liste charge les résultats suivants par lots de 50 au défilement et conserve les charts cochées.
- **Charts signalées par Clone Hero.** Le bouton **Sélectionner tout** coche jusqu’à 200 erreurs admissibles. Après confirmation, le nettoyage poursuit le lot si la corbeille refuse un dossier et signale les éléments conservés. Les avertissements restent protégés.

Les charts de ChorusEncore sont accessibles par la recherche et les téléchargements du catalogue. La synchronisation intégrale concerne le catalogue ChartsHub.
