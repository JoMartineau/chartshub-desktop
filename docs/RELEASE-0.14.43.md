# ChartsHub 0.14.43

L’application signale au site les téléchargements de charts ChartsHub une fois les fichiers vérifiés et enregistrés. Cela couvre les téléchargements individuels et groupés du catalogue, ainsi que la file du tableau de bord et du catalogue flottant.

Le classement utilise ces confirmations pour comptabiliser les téléchargements terminés. Une ouverture du lien source compte séparément comme clic vers la source.
