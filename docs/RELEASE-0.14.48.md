# ChartsHub 0.14.48

- **Catalogue RhythmVerse.** Retrouvez ses charts dans Tout ou dans l’onglet RhythmVerse. Les résultats affichent le charter, les instruments et les difficultés disponibles.
- **Téléchargements sur Windows.** Ouvrez la chart dans votre dossier d’exportation ou enregistrez-la en ZIP ou SNG si le lien est compatible. Les charts compatibles peuvent rejoindre une sélection avec ChartsHub et ChorusEncore.
- **Téléchargements dans le navigateur.** L’app ouvre le lien de l’hébergeur sur macOS et Linux, ainsi que pour les charts que Windows ne peut pas importer directement.
