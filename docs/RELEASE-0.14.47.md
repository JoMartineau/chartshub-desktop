# ChartsHub 0.14.47

- **Fond transparent pour les demandes.** Dans Tableau de bord → Demandes, activez « Fond transparent » pour retirer le fond autour de la file dans le widget flottant. Glissez l’en-tête pour déplacer la fenêtre et appuyez sur Échap pour la fermer. Le mode fond uni permet de redimensionner le widget et de choisir une couleur d’incrustation.
- **Diffusion.** Dans OBS, utilisez le lien du widget dans une source Navigateur pour conserver la transparence. Si une capture de fenêtre affiche un fond opaque, choisissez un fond uni et appliquez l’incrustation couleur dans votre logiciel de diffusion.
