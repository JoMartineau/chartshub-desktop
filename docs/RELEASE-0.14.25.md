# ChartsHub Desktop 0.14.25

La publication de la liste Song Request accepte les morceaux dont les notes
contiennent plusieurs fois la même piste. Une paire instrument/difficulté
apparaît une seule fois dans les métadonnées partagées.

La préparation nettoie les caractères de contrôle et les marques de direction
invisibles dans les textes publiés, y compris depuis un ancien index sans
nouveau scan. Un titre devenu vide est exclu avec les autres morceaux
indisponibles, sans bloquer la liste entière. Les fichiers des chansons et
l’index local restent inchangés.

Les vérifications des données envoyées au serveur, les limites, le lien public
et la première publication volontaire sont conservés.
