# ChartsHub Clone Hero Companion

## Bibliothèque locale — version 0.14.0

La bibliothèque ne fixe aucun plafond au nombre de morceaux, aux entrées
parcourues ou à la taille totale de l'index. Les lectures de métadonnées
individuelles restent bornées. L'analyse et les recherches fonctionnent dans
un worker ; l'index est écrit par lots dans un fichier temporaire puis remplacé
atomiquement. L'annulation conserve le dernier index confirmé.

Les profils d'overlay et le verrouillage des widgets complètent les deux
dispositions Jeu et Stream. Les effets du jeu et leur installation ReShade
restent décrits dans docs/FILTERS.txt et docs/RESHADE.txt.

Le parcours de nettoyage sélectif complète Installed Library : comparer les
versions, enregistrer celle à conserver, vérifier l'audio et tous les fichiers,
cocher explicitement chaque copie puis confirmer dans le dialogue natif
Windows. Aucune case n'est présélectionnée et la version conservée est exclue.

Seuls les dossiers complets identiques (mêmes chemins et mêmes octets pour tous
les fichiers) ou les conteneurs .sng entièrement identiques sont admissibles.
Tous les fichiers audio doivent être vérifiés. Une différence de métadonnées,
de pochette ou de fichier supplémentaire conserve la version ; les comparaisons
mixtes dossier/.sng, les contenus indisponibles et les cibles imbriquées sont
bloqués. Le scanner ordinaire reste une lecture des métadonnées.

La Corbeille reçoit uniquement les cibles cochées et revalidées. Aucun recours
à la suppression définitive n'est autorisé en cas d'échec. L'interface conserve
le bilan des réussites, échecs et annulations pendant l'actualisation automatique.
Chaque plan est lié à l'index et au choix conservé et ne peut servir qu'une fois.

Les tests de ce parcours utilisent des fixtures et une API Corbeille simulée.
Ils n'envoient aucun fichier d'une bibliothèque réelle à la Corbeille et ne
constituent pas une validation de l'interface native en fonctionnement.
L'installation, la fusion de versions différentes et les autres étapes du
plan ci-dessous restent distinctes de cette extension.

Construire dans **ChartsHub Desktop App** un compagnon complet pour Clone Hero.

- Now Playing
- Gameplay State Detection
- Widget Builder

# Architecture fondamentale

Ne pas construire un gros composant :

```text
HugeCloneHeroOverlay
 ├── Now Playing
 ├── Search
 ├── Downloads
 ├── Requests
 ├── OBS
 ├── Library
 ├── Themes
 └── History
```

Construire plutôt :

```text
EXTERNAL SOURCES
        ↓
INTEGRATIONS / ADAPTERS
        ↓
INDEPENDENT SERVICES
        ↓
TYPED EVENT BUS
        ↓
CENTRAL STATE
        ↓
WIDGET ENGINE
        ↓
RENDERERS
```

Architecture cible :

```text
Clone Hero ──────────────┐
ChartsHub API ───────────┤
Filesystem ──────────────┤
Twitch ──────────────────┤
YouTube ─────────────────┘
            ↓
       Integrations
            ↓
         Services
            ↓
      Typed Event Bus
            ↓
        State Store
            ↓
       Widget Engine
        ↙          ↘
Game Renderer   Stream Renderer
                     ↓
              Local Overlay Server
                     ↓
                    OBS
```
